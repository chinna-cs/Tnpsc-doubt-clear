# TNPSC Group 4 - சந்தேகம் தெளிவு

வணக்கம்! TNPSC Group 4 தேர்வுக்கு தமிழ் வழியில் படிக்கும் நண்பர்களுக்காக உருவாக்கப்பட்டது.

**நமது இலக்கு:** கோச்சிங் இல்லாமல், இலவசமாக அனைவரும் அரசு வேலை பெற வேண்டும்.

### 📖 தேர்வு அமைப்பு

மொத்தம் 300 மதிப்பெண்கள் - 3 மணி நேரம்
1.  பொதுத்தமிழ் - 100 கேள்விகள்
2.  பொது அறிவு - 75 கேள்விகள்
3.  திறனறிவு - 25 கேள்விகள்

தேர்ச்சி பெற குறைந்தது 90 மதிப்பெண்கள் எடுக்க வேண்டும்.

### 📚 இங்கு என்ன கிடைக்கும்?

**1. பொதுத்தமிழ் (100 மதிப்பெண்)**
   - இலக்கணம்: எழுத்து, சொல், பொருள், யாப்பு, அணி
   - திருக்குறள் - 20 அதிகாரம் முழுவதும்
   - இலக்கியம் - சங்க இலக்கியம் முதல் இக்கால இலக்கியம் வரை

**2. பொது அறிவு**
   - தமிழ்நாடு வரலாறு, பண்பாடு
   - தமிழ்நாடு புவியியல், இந்திய புவியியல்
   - இந்திய அரசியலமைப்பு
   - அறிவியல் (6-10ம் வகுப்பு சமச்சீர் புத்தகம்)

**3. கணக்கு & பகுத்தறிவு**
   - குறுக்கு வழி (Shortcut) முறைகள் தமிழில்

**4. நடப்பு நிகழ்வுகள்**
   - தினசரி, மாதாந்திர தொகுப்பு - தமிழில்

### 🙏 உதவி செய்யுங்கள்
உங்களுக்கு ஏதாவது சந்தேகம் இருந்தால் `பிரச்சினைகள் (Issues)` பக்கத்தில் தமிழிலேயே கேளுங்கள். தெரிந்தவர்கள் பதில் சொல்வார்கள்.

### நன்றி!

> முயற்சி உடையார் இகழ்ச்சி அடையார்.
